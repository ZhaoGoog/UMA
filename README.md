## Prepare Data

We evaluate our method on public benchmark datasets covering anomaly detection, time series forecasting, and time series classification.

The datasets can be obtained from the following sources. **Due to their size and individual access or usage conditions, the datasets are not included in this repository.** Please download the required datasets from their respective sources and place the files in the `./dataset` directory. Ensure that the downloaded data follows the directory structure and preprocessing format expected by our implementation.

- **MSL and SMAP:** [Telemanom](https://github.com/khundman/telemanom)
- **PSM:** [RANSynCoders](https://github.com/eBay/RANSynCoders/tree/main/data)
- **SMD:** [OmniAnomaly](https://github.com/NetManAIOps/OmniAnomaly/tree/master/ServerMachineDataset)
- **SWaT:** [iTrust Dataset Portal](https://itrust.sutd.edu.sg/itrust-labs_datasets/)
- **Electricity, Exchange Rate, and Solar:** [Multivariate Time Series Datasets](https://github.com/laiguokun/multivariate-time-series-data)
- **ETT-small:** [ETDataset](https://github.com/zhouhaoyi/ETDataset)
- **Weather:** [Jena Weather Data](https://weather.bgc-jena.mpg.de/weather_data.html)
- **UEA Time Series Classification Archive:** [Official Website](https://www.timeseriesclassification.com/)

**Note:** Access to the SWaT dataset requires following the access procedures and usage terms specified by iTrust. The Flight dataset source and download instructions will be provided separately once verified.
